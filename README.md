## 🚀 Proyectos destacados

### 🧾 [Mostrador — gestión para kioscos y comercios](https://github.com/amaroebodrone-pixel/kiosco-gestion)
Sistema web de ventas, stock y caja para kioscos, almacenes y minimercados, pensado como servicio por suscripción.
- Punto de venta con lector de códigos (USB o cámara del celular), productos por peso, pago combinado y atajos de teclado.
- Stock con historial inalterable, caja con arqueo y cierre, roles con permisos validados en el servidor.
- App instalable (PWA) en PC, Android e iPhone. Planes, pruebas gratuitas e invitaciones para vender el sistema a otros comercios.
- **Stack:** Next.js 16 · React 19 · TypeScript · PostgreSQL · Drizzle ORM · Zod · Argon2id · Tailwind CSS 4 · Vitest
- 🔗 **Demo:** [kiosco-gestion-wheat.vercel.app](https://kiosco-gestion-wheat.vercel.app)

### 🛒 Tienda online para LQ Distribuciones _(proyecto para cliente, código privado)_
E-commerce para un distribuidor oficial de herramientas Lusqtoff.
- Catálogo con búsqueda rápida, carrito sin cuenta, checkout con **Mercado Pago** o transferencia, envíos por zona.
- Venta mayorista con descuento por cliente y discriminación de IVA.
- Panel de administración: pedidos, productos con importación CSV, stock, banners, clientes, equipo y registro de auditoría.
- **Stack:** Next.js 16 · TypeScript · PostgreSQL (búsqueda trigram) · Drizzle ORM · Playwright + axe-core (pruebas E2E y accesibilidad)

### 🎛️ [Control de equipo de sonido](https://github.com/amaroebodrone-pixel/app-sonido)
App web para una empresa de sonido e iluminación: inventario de equipos con códigos QR, escaneo desde el celular, equipos en uso y armado de eventos.
- **Stack:** HTML · CSS · JavaScript · html5-qrcode
- 🔗 **Demo:** [amaroebodrone-pixel.github.io/app-sonido](https://amaroebodrone-pixel.github.io/app-sonido/)

### 💊 [Farmacia Arnaudo](https://github.com/amaroebodrone-pixel/farmacia-arnaudo-Final1)
Sitio de cinco páginas para una farmacia de barrio, con catálogo, servicios y pedidos para retirar o recibir.
- **Stack:** HTML5 semántico · SCSS con arquitectura de partials · Bootstrap 5 · CSS Grid · Flexbox · mobile-first
- 🔗 **Demo:** [farmacia-arnaudo.netlify.app](https://farmacia-arnaudo.netlify.app)
